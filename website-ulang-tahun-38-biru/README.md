# Website Ulang Tahun ke-38 — Tema Biru
Template romantis dewasa bernuansa navy, biru es, dan putih dengan gaya editorial/jurnal kenangan. Berbeda dari desain pink sebelumnya: tanpa amplop atau animasi hati dominan, fokusnya pada tipografi, foto, cerita, dan pesan personal.

## Jalankan di VS Code
1. Ekstrak ZIP dan buka folder `website-ulang-tahun-38-biru` di VS Code.
2. Tambahkan foto di folder `assets/foto/` dengan nama `foto-utama.jpg`, `foto-1.jpg`, `foto-2.jpg`, dan `foto-3.jpg`.
3. Opsional: tambahkan musik pilihan sebagai `assets/music.mp3`.
4. Buka `index.html` dengan ekstensi Live Server.

## Personalisasi
Edit teks pada `index.html` agar sesuai dengan nama panggilan, cerita, dan gaya bahasa temanmu. Foto asli tidak disertakan dalam template.

## Deploy ke GitHub Pages
Buat repository baru, upload isi folder (bukan ZIP), lalu pilih **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Link biasanya berbentuk `https://USERNAME.github.io/NAMA-REPOSITORY/`.

## Privasi
Pastikan kedua orang setuju dengan foto yang dipublikasikan. Repository Public dan foto yang ada di dalamnya dapat dilihat orang lain.
